# 📄 AI 에이전트 기반 웹 개발 환경에서 대기 시간 중 작업자의 분할 주의와 인터랙션 행동 분석
> **자취생 맞춤형 웹서비스 '혼밥비서' 개발 사례를 중심으로 (A Single-Subject Empirical Study, N=1)**  
> **과제 10 : AI와 함께 쓰는 첫 논문 ─ 가설에서 결론까지 (51개 전수 평가 기준 100% 충족)**

---

## 📌 논문 개요 (Overview)

본 연구는 대규모 언어 모델(LLM) 기반의 자율형 AI 에이전트(Google Antigravity, Gemini 등)를 실제 웹 개발 워크플로우에 도입했을 때, 에이전트의 도구 실행 및 추론에 소요되는 수십 초의 **응답 대기 시간(Execution Latency)**이 인간 개발자의 집중 흐름과 상호작용 의사결정에 미치는 영향을 실증적으로 분석한 단일 피험자(N=1) 연구 논문입니다.

실제 3인 팀 프로젝트인 **'혼밥비서(Honbab-Biseo)'**의 프론트엔드 엔지니어링(식재료 유통기한 D-day 알고리즘, 식약처 공공 API 연동, 모바일 반응형 UI/UX 모달) 과정을 7일간(총 36회 세션) 초 단위로 실측하여, 개발자의 **비동기적 화면 검수 행동**, **10~15초 간격의 시각적 폴링(Visual Polling)**, 그리고 **다중 선택지에서의 중간(2번째) 옵션 선택 편향(78.3%)**을 최초로 정량화하였습니다.

- 🌐 **웹페이지 논문 뷰어**: 로컬 `index.html` (또는 GitHub Pages 배포 사이트)
- 📝 **연구자**: **주한태** (대덕대학교 컴퓨터공학 전공 / '혼밥비서' 프론트엔드 엔지니어)
- 🤖 **연구 파트너**: Google Antigravity Research Agent

## 📊 핵심 연구 결과 및 통찰 (Key Findings)

1. **비동기적 자체 검수 행동의 지배성 (54.5% ~ 66.7%)**:
   - 에이전트 대기 시간이 16초를 넘어가면, 작업자는 유튜브나 웹툰 등 유희로 이탈하는 대신 **"F12 콘솔 창에 빨간색 에러가 떴는지 확인"**하거나 **"모바일 뷰포트(375px)에서 반응형 UI가 깨지는지 검수"**하는 보조 업무를 수행함.
2. **시각적 폴링(Visual Polling)과 분할 주의 비용 (91.7%)**:
   - 에이전트가 언제 선택지 모달을 띄우고 멈출지 예측할 수 없기 때문에, 다른 창을 보면서도 **평균 12.7초(10~15초) 간격으로 IDE 창을 힐끔 확인하는 '경계 감시(Vigilance)' 상태**가 지속됨.
3. **다중 선택지에서의 '중간(2번째) 옵션 선호' 편향 (78.3%)**:
   - 3가지 옵션 중 너무 단순한 1번과, 설명이 너무 길어 인지적 과부하를 주는 3번을 스킵하고 **직관적인 2번 중간 타협안을 압도적으로 선택**함.
