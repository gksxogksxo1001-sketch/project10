# [실험 설계서] AI 에이전트 대기 시간과 작업자 상호작용 실측 연구

본 문서는 과제 10 가이드라인의 **3단계 통과 기준(T10-C21 ~ T10-C30)**을 충족하는 실험 설계 및 변수 통제 명세서입니다.

---

## 1. 실험 설계 요약 및 표본 수 (T10-C21, T10-C23)
- **연구 대상**: '혼밥비서' 웹서비스 프론트엔드 엔지니어 1인 (주한태, N=1 단일 대상 종단 연구)
- **실험 기간**: 2026년 10월 14일 ~ 10월 21일 (7일간)
- **총 표본 수 (반복 횟수)**: **총 36회 세션** (T10-C26: 원자료 CSV 파일의 건수 36건과 100% 일치)

---

## 2. 통제 변수와 독립 변수 구분 (T10-C22)

실험의 내적 타당도(Internal Validity)를 확보하기 위해 다음 표와 같이 **고정한 조건(통제변수)**과 **바꾼 조건(독립변수)**을 엄격히 구분하여 통제하였습니다.

| 구분 | 조건 항목 | 구체적 통제 및 조작 내용 |
| :--- | :--- | :--- |
| **고정한 조건**<br>(통제변수) | **피험자** | 주니어 웹 프론트엔드 개발자 1인 (주한태) 고정 |
| | **대상 프로젝트** | '혼밥비서(Honbab-Biseo)' 단일 웹 애플리케이션 과업 고정 |
| | **개발 스택** | HTML, CSS, Vanilla JavaScript 프론트엔드 환경 고정 |
| | **AI 도구** | Google Antigravity IDE (Gemini 모델 엔진) 단일 도구 고정 |
| | **작업 환경** | 동일한 데스크톱 환경 및 배경음악(BGM) 청취 상태 고정 |
| | **질문 전달 방식** | 10분 자체 디버깅 후 에러 스크린샷 첨부 및 3~5줄 구조화 프롬프트 고정 |
| **바꾼 조건**<br>(독립변수) | **에이전트 지시 태스크의 복잡도** | 1) 단순 UI 스타일/텍스트 수정 (대기 시간 0~15초 유도)<br>2) DOM 이벤트 및 중간 비즈니스 로직 작성 (대기 시간 16~30초 유도)<br>3) 복합 공공 API 비동기 처리 및 다중 도구 실행 (대기 시간 31초 이상 유도) |
| | **결과적 응답 대기 시간** | 에이전트가 코드를 완성하거나 선택지를 띄울 때까지의 경과 시간 (초) |

## 3. 측정한 종속변수 값 및 지표 정의 (T10-C24)

1. **독립변수 실측치 (`Latency_Sec`)**: 사용자 프롬프트 전송 시각부터 에이전트 완료/모달 제시 시각까지의 시간 (단위: 초).
2. **종속변수 1 (`Action_Type`)**: 대기 시간 중 작업자의 행동 상태를 다음 3가지로 범주형 기록:
   - `IDE 지속 주시`: 에디터 창을 벗어나지 않고 실시간 코드 diff 및 스트리밍 응시.
   - `혼밥비서 화면 검수`: 브라우저로 전환하여 F12 콘솔 에러 확인 또는 모바일 반응형 뷰 깨짐 점검.
   - `모바일 확인`: 스마트폰 메신저, SNS 등 외부 알림 확인.
3. **종속변수 2 (`Visual_Polling`)**: 타 창/모바일 확인 중 에이전트의 확인 모달 발생 여부를 보기 위해 IDE 창을 힐끔 쳐다본 주기 (단위: 초).
4. **종속변수 3 (`Modal_Choice`)**: 에이전트가 3지 선다 모달을 제시했을 때 선택한 옵션 번호 (1번 / 2번 / 3번).

---

## 4. 공개 데이터 출처 및 연동 내역 (T10-C27)
- **사용 데이터**: 식품의약품안전처(MFDS) 식품영양성분DB 오픈 API (공공데이터포털 운영)
- **출처 기관**: 공공데이터포털(data.go.kr) 및 식품의약품안전처
- **연동 일자**: 2026년 10월 14일 ~ 10월 21일 (개발 기간 중 실시간 비동기 REST API 호출 연동)
