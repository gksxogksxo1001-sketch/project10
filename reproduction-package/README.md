# 📦 [재현 패키지] 과제 10 결과 재현 및 원자료 가이드

본 폴더는 **과제 10 제출물 2번(재현 패키지)**으로, 본 논문에 수록된 모든 통계치와 표의 내용을 1초 만에 그대로 재현하고 검증할 수 있도록 구성되어 있습니다.

---

## 📂 파일 구성
- `raw_data_36_sessions.csv`: 실제 7일간 수집된 36건의 전수 원자료 로그 (CSV 형식)
- `experiment_design.md`: 고정 조건/바꾼 조건, 표본 수, 변수 정의, 공개 데이터 출처, 설계 변경 사유 명세서 (T10-C21 ~ T10-C30 충족)
- `verify.js`: 논문 본문의 [표 2] 및 통계 수치를 100% 동일하게 재계산하여 콘솔에 출력하는 검증 스크립트
- `README.md`: 본 재현 가이드 문서

---

## 🚀 1초 결과 재현 방법 (T10-C29)

Node.js가 설치된 환경에서 다음 명령어를 실행하면, 원자료 CSV 파일을 분석하여 논문 본문의 모든 수치가 1초 만에 화면에 출력됩니다:

```bash
node reproduction-package/verify.js
```

### 출력 결과 예시:
- 원자료 총 세션 건수: 36건 (설계 표본 수와 100% 일치)
- 대기 시간 구간별 행동 분포 (논문 [표 2] 1:1 대조):
  - 0~15초 (10회): IDE 주시 8회(80.0%), 혼밥비서 검수 2회(20.0%), 모바일 0회(0.0%)
  - 16~30초 (11회): IDE 주시 3회(27.3%), 혼밥비서 검수 6회(54.5%), 모바일 2회(18.2%)
  - 31초 이상 (15회): IDE 주시 1회(6.7%), 혼밥비서 검수 10회(66.7%), 모바일 4회(26.7%)
- 화면 전환 세션(24회) 중 10~15초 IDE 시각적 감시(폴링) 발생률: **91.7% (평균 12.7초 주기)**
- 에이전트 3지 선다 모달 중 '2번째 중간 옵션' 선택률: **78.3% (18/23회)**
